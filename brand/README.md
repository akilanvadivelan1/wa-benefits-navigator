# Brand & Cover Assets

Downloadable images for the WA Benefits Navigator submission, demo video, and promotion.

## Files

| File | Size | Use it for |
|------|------|-----------|
| `cover.png` | 1280 x 720 | YouTube/Vimeo video thumbnail, or a title card at the start of your demo video |
| `cover@2x.png` | 2560 x 1440 | High-resolution version of the cover for crisp display or print |
| `website-design.png` | 1400 x 1000 | A clean mockup of the website design (home page in a browser frame) |
| `website-design@2x.png` | 2800 x 2000 | High-resolution version of the website design mockup |
| `cover.svg`, `website-design.svg` | vector | Source files. Edit text/colors and re-export if needed. |

## How to download

Option 1 (easiest): on GitHub, open the file (for example `brand/cover.png`), then click the download icon or right-click the image and choose "Save Image As".

Option 2: clone or pull the repo and the files are in the `brand/` folder on your computer.

## Colors used (brand palette)

- Teal primary: `#0E7C74`
- Teal light: `#16A79B`
- Coral accent: `#FB7185`
- Warm background: `#FBF9F6`

## Notes

- PNGs have no transparency and are ready to upload directly.
- To change any text or color, edit the matching `.svg` file and re-export to PNG.
